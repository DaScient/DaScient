UFO Intel Widget

A self-contained, embeddable Web Component delivering a live intelligence feed, a BYO-key agentic assistant with fully client-side RAG, and interactive deep-analytics over UFO/UAP release archives. Drop the tag into any page and go. 

<script type="module" src="ufo-intel-widget.html#component"></script>
<ufo-intel-widget
   data-source="https://example.gov/ufo/manifest.json"
   llm-provider="openai"
   refresh-interval="30000"
   theme="dark"></ufo-intel-widget>
All processing is local. API keys live only in localStorage. Visualisation libraries (D3, Chart.js) and the embeddings model (Transformers.js / Xenova MiniLM) are loaded lazily from CDNs only when their feature is first used — URLs are configurable in the settings panel.
